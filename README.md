# Copy Excel

Графическая утилита для копирования выбранных строк из Excel-файла в новый файл.

## Возможности

- Выбор исходного файла `.xlsx` / `.xls` через диалог.
- Отображение таблицы с чекбоксами для выбора отдельных строк.
- Чекбокс «Выбрать все» для выбора/снятия всех строк сразу.
- Счётчик: общее число строк и количество выбранных (`Выбрано: M из N`).
- Сохранение выбранных строк в новый Excel-файл через диалог «Сохранить как».

## Требования

- Python 3.14+
- Зависимости из `requirements.txt`

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows (cmd)
pip install -r requirements.txt
```

## Запуск

```bash
.venv\Scripts\python.exe main.py
```

## Использование

1. Нажмите **«Выбрать файл»** и укажите Excel-файл.
2. Отметьте нужные строки (или **«Выбрать все»**).
3. Нажмите **«Копировать»**, выберите место и имя для сохранения нового файла.

## Структура

- `main.py` — графический интерфейс (customtkinter) и логика копирования.
- `get_file.py` — диалоги выбора и сохранения файла.
- `requirements.txt` — зависимости проекта.
